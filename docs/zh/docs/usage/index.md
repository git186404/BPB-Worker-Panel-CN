# :material-playlist-check:{ .md .middle } 使用说明

![使用说明](../images/usage.jpg)

本部分提供了如何使用面板以及不同订阅之间区别的教程。

面板提供了四种不同的订阅链接：

<div class="grid cards" markdown>

- :material-playlist-check:{ .lg .middle } __普通订阅 (Normal)__

    ---

    应用所有最佳设置，将用户错误降至最低。

    [:octicons-arrow-right-24: 使用说明](normal.md)

- :material-playlist-check:{ .lg .middle } __分片订阅 (Fragment)__

    ---

    专为解决 Cloudflare 及其地址被运营商屏蔽的情况而设计。

    [:octicons-arrow-right-24: 使用说明](fragment.md)

- :material-playlist-check:{ .lg .middle } __Warp 订阅__

    ---

    官方 Cloudflare Warp 订阅，旨在改善隐私并将连接掩盖为常规流量。

    [:octicons-arrow-right-24: 使用说明](warp.md)

- :material-playlist-check:{ .lg .middle } __Warp PRO 订阅__

    ---

    针对 Warp 方案被运营商阻断的网络环境而设计的优化版 Warp 订阅。

    [:octicons-arrow-right-24: 使用说明](warp-pro.md)

</div>
