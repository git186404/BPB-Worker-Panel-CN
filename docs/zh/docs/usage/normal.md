# :material-playlist-check:{ .md .middle } 普通订阅 (Normal)

![普通订阅](../images/normal-sub.jpg)

此订阅应用了所有优化的 VLESS 和 Trojan 设置、DNS 服务器、路由规则等，从而将用户操作错误降至最低。它还包含一个 **Best Ping**（最佳 Ping）配置。

???+ question "什么是 **Best Ping** 配置？"
    此配置汇总了面板中的所有子配置，并每 30 秒进行一次检查，以识别并连接到速度最快的一个。如果您添加了优选 IP、启用了 Trojan 协议或选择了额外端口，这些也将包含在 **Best Ping** 配置中。该功能在分片 (Fragment) 和 Warp 订阅中同样可用。

应用路由设置后，该订阅将拦截约 90% 的伊朗和国外广告，绕过伊朗、中国和俄罗斯网站（访问支付网关时无需关闭 VPN），绕过局域网，拦截色情内容和 QUIC 协议。对于 Sing-box 和 Clash 订阅，它还能有效拦截钓鱼网站和恶意软件内容。
