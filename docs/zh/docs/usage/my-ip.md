# :material-fingerprint:{ .md .middle } 我的 IP

![我的 IP](../images/my-ip.jpg)

连接代理后，刷新此页面并检查以查看您的 IP。表格显示两行：

- 第一行显示您访问 Cloudflare 目标地址时的节点 IP。如果设置了代理 IP (Proxy IP)，这将是您访问 Cloudflare 地址时的 IP，而访问其他目标地址时将使用随机的 Cloudflare IP。这可以帮助您验证代理 IP 是否正常工作。
- 如果使用 Warp 配置，两行应显示相同的 IP。

!!! warning "警告"
    请禁用 `uBlock` 或 `AdGuard` 等扩展程序，否则此部分可能无法正常工作。
