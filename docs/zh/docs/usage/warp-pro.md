# :material-playlist-check:{ .md .middle } Warp Pro 订阅

![Warp Pro 订阅](../images/warp-pro-sub.jpg)

随着 Xray、GFW-Knocker 以及 Mihomo 内核的最新进展，现在已实现了对 Warp 的解禁，并衍生出了 **MahsaNG** 和 **v2rayN-PRO** 等应用。这些进展针对特定网络环境优化了 Warp 连接。面板中加入了 **Warp Pro** 订阅，并提供可自定义的设置。

各运营商的最佳数值通常需要通过反复试验来确定，且可能随时间变化（类似于分片设置）。目前的默认值经过测试是有效的；您只需扫描并设置优选端点 (Endpoints) 即可。

您可以下载 Warp Pro 配置的压缩包，用于 **WG Tunnel** 客户端。在客户端中点击 `+` 并导入压缩包即可，无需额外设置即可连接。对于 **Amnezia**，过程类似，但 Amnezia 无法正确导入压缩包。请先解压压缩包，然后将所需的每个配置分别导入 Amnezia 并连接。
